## 核心功能特性

### 1. 深色/明亮模式切換
- **即時主題切換**: 用戶可隨時切換深色科技感和明亮模式
- **主題持久化**: 使用 localStorage 保存用戶偏好
- **系統主題檢測**: 自動匹配操作系統主題設置
- **平滑過渡**: CSS 過渡動畫實現無縫主題切換

### 2. 響應式設計
- **移動優先**: 適應手機、平板、桌面各種屏幕尺寸
- **彈性網格**: CSS 網格佈局自動調整遊戲卡片列數
- **觸控友好**: 適合觸控設備的按鈕大小和間距
- **設備方向適應**: 支持橫向和縱向模式

### 3. 遊戲中心功能
- **遊戲卡片展示**: 美觀的卡片式遊戲列表
- **遊戲分類標籤**: 顯示遊戲類型和難度
- **一鍵開始**: 直接進入遊戲頁面
- **遊戲統計**: 顯示遊戲數量和特色

### 4. 無障礙功能
- **語義化 HTML**: 正確的標題層級和地標角色
- **鍵盤導航**: 所有功能均可通過鍵盤訪問
- **屏幕閱讀器支持**: 適當的 ARIA 屬性和文字替代
- **對比度合規**: 符合 WCAG 2.1 AA 標準的顏色對比度

## 視覺設計

### 深色科技感主題
```
背景: 深藍漸層 (#1e3a5f → #0d1b2a)
文字: 白色 (#ffffff) + 金色 (#ffd700)
卡片: 半透明深藍背景 + 金色邊框
按鈕: 金色漸層 + 深藍文字
```

### 明亮模式主題
```
背景: 淺灰漸層 (#f5f7fa → #e4e8f0)
文字: 深藍 (#1e3a5f) + 中灰 (#666666)
卡片: 白色背景 + 淺藍邊框
按鈕: 藍色漸層 + 白色文字
```
