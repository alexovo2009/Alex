# Alex's Game Center 測試計劃

## 測試概述
本測試計劃涵蓋 Alex's Game Center 的所有功能測試，包括主題切換、遊戲導航、響應式設計和無障礙功能。

## 測試環境

### 瀏覽器兼容性測試
- Chrome (最新版)
- Firefox (最新版)
- Safari (最新版)
- Edge (最新版)

### 設備測試
- 桌面電腦 (1920x1080, 1366x768)
- 平板電腦 (iPad, 1024x768)
- 手機 (iPhone, Android, 375x667)

### 操作系統
- Windows 10/11
- macOS
- iOS
- Android

## 功能測試用例

### 1. 主題切換功能測試

#### 測試用例 1.1: 主題切換按鈕
- **描述**: 測試主題切換按鈕的功能
- **步驟**:
  1. 訪問首頁
  2. 點擊右上角的主題切換按鈕
  3. 觀察頁面顏色變化
  4. 再次點擊按鈕切換回原主題
- **預期結果**:
  - 按鈕點擊後主題立即切換
  - 顏色過渡平滑無閃爍
  - 按鈕圖標正確更新（🌙/☀️）

#### 測試用例 1.2: 主題持久化
- **描述**: 測試主題設置在頁面刷新後是否保持
- **步驟**:
  1. 切換到明亮模式
  2. 刷新頁面
  3. 檢查主題是否保持為明亮模式
  4. 切換到深色模式
  5. 刷新頁面
  6. 檢查主題是否保持為深色模式
- **預期結果**: 主題設置在頁面刷新後保持不變

#### 測試用例 1.3: 系統主題檢測
- **描述**: 測試首次訪問時是否檢測系統主題
- **步驟**:
  1. 清除瀏覽器 localStorage
  2. 在系統設置為深色模式時訪問頁面
  3. 檢查頁面是否自動使用深色主題
  4. 在系統設置為明亮模式時訪問頁面
  5. 檢查頁面是否自動使用明亮主題
- **預期結果**: 頁面自動匹配系統主題偏好

### 2. 遊戲導航測試

#### 測試用例 2.1: 遊戲卡片連結
- **描述**: 測試所有遊戲卡片的連結是否正確
- **步驟**:
  1. 點擊「貪食蛇遊戲」卡片
  2. 驗證是否正確跳轉到 game1.html
  3. 返回首頁
  4. 重複測試其他遊戲卡片
- **預期結果**: 所有遊戲卡片正確跳轉到對應遊戲頁面

#### 測試用例 2.2: 遊戲卡片懸停效果
- **描述**: 測試遊戲卡片的懸停視覺效果
- **步驟**:
  1. 將鼠標懸停在遊戲卡片上
  2. 觀察卡片是否上浮並顯示陰影
  3. 移開鼠標觀察恢復效果
- **預期結果**: 卡片有平滑的懸停動畫效果

#### 測試用例 2.3: 遊戲頁面功能
- **描述**: 測試遊戲頁面的基本功能
- **步驟**:
  1. 進入每個遊戲頁面
  2. 檢查遊戲是否能正常啟動
  3. 測試遊戲基本控制
  4. 檢查是否有返回首頁的連結
- **預期結果**: 所有遊戲頁面功能正常

### 3. 響應式設計測試

#### 測試用例 3.1: 桌面版佈局
- **描述**: 測試桌面設備上的佈局
- **步驟**:
  1. 在桌面瀏覽器中打開頁面
  2. 檢查遊戲卡片是否顯示為 4 列網格
  3. 檢查導航欄是否水平排列
  4. 檢查字體大小和間距是否合適
- **預期結果**: 桌面版佈局美觀且功能完整

#### 測試用例 3.2: 平板版佈局
- **描述**: 測試平板設備上的佈局
- **步驟**:
  1. 將瀏覽器窗口調整到平板尺寸 (768px-1024px)
  2. 檢查遊戲卡片是否顯示為 2 列網格
  3. 檢查導航欄是否適應屏幕
  4. 檢查觸控元素大小是否合適
- **預期結果**: 平板版佈局適應屏幕尺寸

#### 測試用例 3.3: 手機版佈局
- **描述**: 測試手機設備上的佈局
- **步驟**:
  1. 將瀏覽器窗口調整到手機尺寸 (<768px)
  2. 檢查遊戲卡片是否顯示為 1 列
  3. 檢查導航欄是否變為垂直排列
  4. 檢查按鈕和連結大小是否適合觸控
- **預期結果**: 手機版佈局清晰易用

#### 測試用例 3.4: 橫向/縱向模式
- **描述**: 測試設備旋轉時的佈局適應
- **步驟**:
  1. 在手機或模擬器中打開頁面
  2. 旋轉設備到橫向模式
  3. 檢查佈局是否正確調整
  4. 旋轉回縱向模式
  5. 檢查佈局是否恢復
- **預期結果**: 佈局正確適應設備方向

### 4. 無障礙功能測試

#### 測試用例 4.1: 鍵盤導航
- **描述**: 測試僅使用鍵盤是否能訪問所有功能
- **步驟**:
  1. 使用 Tab 鍵瀏覽頁面
  2. 檢查所有互動元素是否可聚焦
  3. 使用 Enter/Space 鍵激活按鈕和連結
  4. 測試主題切換按鈕的鍵盤操作
- **預期結果**: 所有功能均可通過鍵盤訪問

#### 測試用例 4.2: 屏幕閱讀器兼容性
- **描述**: 測試屏幕閱讀器是否能正確讀取頁面內容
- **步驟**:
  1. 使用屏幕閱讀器（如 NVDA、VoiceOver）訪問頁面
  2. 檢查所有元素的 ARIA 標籤是否正確
  3. 檢查語義化 HTML 結構是否合理
  4. 檢查圖標是否有文字替代
- **預期結果**: 屏幕閱讀器能正確讀取頁面內容

#### 測試用例 4.3: 對比度檢查
- **描述**: 測試文字與背景的對比度是否符合 WCAG 標準
- **步驟**:
  1. 使用對比度檢查工具（如 axe DevTools）
  2. 檢查深色主題下的對比度
  3. 檢查明亮主題下的對比度
  4. 特別檢查小字體和次要文字的對比度
- **預期結果**: 所有文字對比度達到 WCAG AA 標準

### 5. 性能測試

#### 測試用例 5.1: 頁面加載速度
- **描述**: 測試頁面加載性能
- **步驟**:
  1. 使用瀏覽器開發者工具測量加載時間
  2. 檢查首次內容繪製 (FCP) 時間
  3. 檢查最大內容繪製 (LCP) 時間
  4. 檢查累計佈局偏移 (CLS)
- **預期結果**: 頁面加載時間 < 3秒，核心網頁指標良好

#### 測試用例 5.2: 主題切換性能
- **描述**: 測試主題切換時的性能
- **步驟**:
  1. 快速多次點擊主題切換按鈕
  2. 觀察是否有性能問題或閃爍
  3. 檢查 CPU 使用率是否正常
- **預期結果**: 主題切換流暢，無性能問題

### 6. 跨瀏覽器兼容性測試

#### 測試用例 6.1: CSS 功能兼容性
- **描述**: 測試 CSS 功能在各瀏覽器的兼容性
- **步驟**:
  1. 在不同瀏覽器中測試 CSS 網格佈局
  2. 測試 CSS 變數支持
  3. 測試 CSS 過渡和動畫
  4. 測試 Flexbox 佈局
- **預期結果**: 所有 CSS 功能在目標瀏覽器中正常工作

#### 測試用例 6.2: JavaScript 兼容性
- **描述**: 測試 JavaScript 功能在各瀏覽器的兼容性
- **步驟**:
  1. 測試 localStorage 功能
  2. 測試 matchMedia API
  3. 測試事件監聽器
  4. 測試 ES6+ 語法兼容性
- **預期結果**: 所有 JavaScript 功能在目標瀏覽器中正常工作

## 缺陷管理

### 缺陷嚴重程度分類
- **嚴重**: 功能完全無法使用
- **高**: 主要功能受影響但可繞過
- **中**: 次要功能問題或UI問題
- **低**: 輕微問題，不影響功能使用

### 缺陷修復優先級
1. 嚴重缺陷 - 立即修復
2. 高優先級缺陷 - 在下一版本修復
3. 中優先級缺陷 - 在計劃時間內修復
4. 低優先級缺陷 - 在有空時修復
